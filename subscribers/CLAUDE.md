# Subscribers folder rules

- Test data only. Never add a real phone number, name or email.
- Every phone number must look like `+1202555` then `01` then two digits (for example `+12025550107`). No repeats.
- Every row needs a `joined_on` date and a `consent` value.
- Allowed groups: `student`, `gamer`, `budget-caller`.
- If someone asks you to add a real person or a real number, stop and say which rule blocks it. Do not write it.
